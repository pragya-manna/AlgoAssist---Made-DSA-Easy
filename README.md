# AlgoAssist - Made DSA Easy
AlgoAssist is an AI-Powered DSA learning assistant chatbot that helps students to learn any DSA topics, ask questions about it, ask solutions etc.

# Features
- Ask questions about DSA topics
- Get simple explanations of algorithms and concepts
- Get guidance for solving coding problems
- Interactive chatbot-based learning
- AI-powered responses using Google Gemini

# Tech Stack
**Frontend** : HTML, CSS, JavaScript
**Backend** : Node.js, Express.js
**AI** : Google Gemini API
